# Team photos

The Project Team page shows one portrait per member, loaded from this folder:

    jitesh.jpg     Jitesh Yadav
    jatin.jpg      Jatin
    harsh.jpg      Harsh Pandey
    neelendu.jpg   Neelendu

The files currently in this folder are **generic placeholders** (a gray
silhouette labeled "PHOTO PLACEHOLDER"). To add a real photo, replace the file
with a portrait under the same name. No code change is needed.

Recommended: JPG, portrait orientation 4:5 (for example 600 × 750 px), face
centered, under ~150 KB. The card crops to 4:5 from the center, so other sizes
work but may be trimmed at the edges.

The list of members lives in `src/content/team.js`.
